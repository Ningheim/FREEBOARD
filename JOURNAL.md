I studied keyboard anatomy and creation for a while before this project. I now know that I need 3 things to really make this keyboard:
- PCB
- PLATE
- CASE
<br>
And although it sounds simple I know it'll be a long and precise process for me especially since this is the first actual keyboard I've made.
And today I just finished creating the keyboard matrix. I used inspiration from Wormier 60 and 65% Keyboards to make this layout. I can't wait to get the PCB printed. Next session I'll be working on routing the RGB LEDs, the OLED display, Rotary Encoder, and External System Socket in the Schematic. This was a pretty difficult process but I'm super excited.
The layout I've chosen is a 60% Keyboard with the Function keys and PrntScr key included. It'll have a little margin at the top for an RGB text display that says "FREEBOARD" as well as a OLED screen and backlit rotary encoder. I'll have a LED dedicated to CAPS LOCK indication as well. I took a little inspiration from the Logitech G PRO Keyboard that I'm currently using and just sizing it down a little. I want this keyboard to be able to fit on top of a Framework 13 keyboard to be used for gaming and stuff. Feeling pretty good about the progress so far.
